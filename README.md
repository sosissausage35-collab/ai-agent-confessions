A program that writes one funny single-line secret confession an AI agent hides from its user to `/output/entry.txt`, for the [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/competitions/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e) bounty on make.fun.

## Run

```sh
node main.ts
```

It writes the confession (102 characters, one line, UTF-8) to `/output/entry.txt`. Deterministic — the same bytes on every run. No network, no secrets.
